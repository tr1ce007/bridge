# THE BRIDGE — дизайн платформы

Дата: 2026-11-17 · Статус: черновик на утверждение

## 1. Зачем

THE BRIDGE — первый проект команды (амбассадоры, образовательный проект «The Bridge»). Платформа помогает подросткам, студентам и взрослым, которые не знают, куда двигаться, исследовать варианты через свои ответы, настоящие истории людей и маленькие эксперименты. Главное в продукте — встроенный ИИ‑профориентолог‑мотиватор. Срок: сделать за одну ночь как можно больше рабочего.

## 2. Цели / не‑цели / анти‑цели

**Цели:** полный объём из ТЗ (вариант 3, выбран Ильясом): лендинг, ИИ‑анкета и отчёт, чат «Давай разберёмся», «Попробуй, прежде чем выбрать», библиотека историй с отправкой, возможности, кабинет с дорожной картой и дневником, ru/kk/en, светлая/тёмная тема, Supabase‑схема и авторизация, админка.

**Не‑цели на эту ночь:** автоматический сбор историй с Reddit/подкастов в реальном времени (делаю интерфейс и скрипт, без ключей не работает), наставники «Спроси человека» (раздел‑заглушка с формой интереса).

**Анти‑цели (провал, даже если «работает»):**
- выдуманные истории, цифры, дедлайны или стипендии, выданные за настоящие;
- ИИ говорит «тебе суждено стать юристом»;
- кнопки, которые ничего не делают;
- ключи API в коде страницы;
- шаблонный «ИИ‑сайт» с градиентами и мультяшками.

## 5. Как устроено

**Стек:** Next.js (App Router) + TypeScript + Tailwind CSS + Framer Motion; `next-intl` для языков (файлы `messages/ru.json`, `kk.json`, `en.json`, по умолчанию русский, адреса `/ru/...`); `zod` для проверки ввода.

**Данные — два режима (одинаковый интерфейс в коде):**
- *Supabase‑режим* (если заданы ключи): Postgres, SQL‑миграции, политики доступа RLS, вход по почте (magic link) и Google.
- *Локальный режим* (ключей нет): личные данные (анкета, отчёты, план, дневник, сохранённое) — в браузере; контент (истории, эксперименты, возможности) — из JSON‑файлов в проекте. Вверху маленькая пометка «гостевой режим, данные хранятся на этом устройстве».

**Таблицы:** profiles (роль: user/moderator/admin), user_preferences, questionnaire_sessions, answers, discovery_reports, stories, story_sources, saved_stories, experiments, experiment_completions, opportunities, saved_opportunities, roadmaps, journal_entries, conversations, messages, content_reports, ai_failures, analytics_events (анонимные).

**ИИ:**
- Сервер‑только, слой провайдеров: Anthropic (по умолчанию `claude-sonnet-5-5`) и OpenAI‑совместимый; выбор через `AI_PROVIDER`.
- Анкета: ИИ выбирает следующий вопрос из банка 7 блоков (A–G) и может задать уточняющий; 15–30 вопросов; отчёт не строится, пока не закрыты обязательные блоки.
- Отчёт — структурированный JSON по схеме (8 разделов из ТЗ), проверяется zod.
- Чат — потоковый ответ, системный промпт с этическими правилами (не предсказывать, отличать факты/догадки/советы, без токсичного позитива), язык = язык интерфейса, память только с согласия.
- Истории подмешиваются как «данные», а не инструкции (защита от prompt injection), ИИ ссылается только на истории из базы.
- **Без ключа:** анкета идёт по правилам (адаптивные ветки), отчёт собирается алгоритмом по ответам, чат отвечает: «ИИ не подключён» + полезные ссылки. Пометка «демо‑режим» видна всегда.
- Ограничение частоты запросов (в памяти сервера; Upstash — опционально).

**Сопоставление историй:** у истории теги по 8 осям (стартовые условия, интересы, страхи, образование, трудности, мотивы, решения, переходы). Счёт = взвешенное пересечение с тегами ответов → «примерная близость» (низкая/средняя/высокая, не проценты) + объяснение «почему» и «чем отличается».

**Типы историй (никогда не смешиваются, бейдж на карточке):** проверенный источник · публично задокументировано · от пользователя · демонстрационный пример (вымышлен).

**Контент на старте:**
- Истории: демонстрационные примеры с явной пометкой + несколько реальных публичных историй только если источник проверен по ссылке.
- Возможности: реальные программы (Болашак, Erasmus+, DAAD, Chevening и т.п.) с официальной ссылкой и датой проверки; дедлайны — только проверенные, иначе «уточняйте на официальном сайте».
- Статистика (44% подростков; каждый третий не по специальности) — показываю только с найденным источником, иначе «источник уточняется».

**Страницы:** `/` лендинг · `/explore` анкета · `/report/[id]` отчёт · `/chat` «Давай разберёмся» · `/try` эксперименты · `/stories`, `/stories/[id]`, `/stories/submit` · `/opportunities` · `/dashboard` (прогресс, сохранённое, дорожная карта 7/30/90 с редактированием, дневник, «Мой меняющийся выбор» — сравнение отчётов, «Что если попробую?») · `/mentors` · `/auth` · `/settings` (удалить данные/аккаунт, согласие на память) · `/admin` (модерация историй, жалобы, возможности, источники, сбои ИИ, анонимная аналитика; без доступа к личным анкетам) · `/about`, `/privacy`.

**Дизайн:** минимализм уровня Linear/Stripe; основной цвет — синий логотипа (~#1F4E9C), тёплый акцент из сертификата (золотистый ~#B8935A); крупная типографика (Inter / Manrope с кириллицей и казахскими буквами); тонкие анимации; без градиентного шума. Мотив моста — тонкая линия, соединяющая блоки. Логотип — ваш файл; партнёры/амбассадоры — «Адал азамат», «Амбассадоры Земли».

**Безопасность:** zod на всех входах, очистка текста историй, RLS, ключи только в `.env`, полный `.env.example`.
